Streamio is astreaming app that combines a imbd catalog  and a live media source handling. 
The app is designed to work as a browser-based streaming hub .


Getting Started

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
